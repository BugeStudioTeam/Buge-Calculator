**Buge Calculator** is a powerful, privacy-first Android scientific calculator built with **Kotlin**, **Jetpack Compose**, and **Material Design 3**. It combines precise expression evaluation, interactive function graphing, 3D formula surfaces, safe local mathematical Python, multilingual support, and a refined adaptive interface.

## ✨ Features

### 🚀 Core Capabilities

| Feature                             | Description                                                                      |
| ----------------------------------- | -------------------------------------------------------------------------------- |
| **Scientific Evaluation**           | Parses and evaluates expressions with functions, powers, roots, factorials, and combinatorics |
| **Interactive Function Graphing**   | Plots mathematical functions with pan, pinch-to-zoom, grid controls, and reset view |
| **3D Formula Surfaces**             | Renders `z = f(x, y)` surfaces with direct rotation, zooming, and camera reset  |
| **Privacy-First**                   | No ads, no analytics, no account sign-in, and no cloud backend — calculations stay on your device |

---

### 🎵 Scientific Calculator

- Switch between **Basic** and **Scientific** keypad modes
- Evaluate arithmetic, brackets, powers, roots, percentages, and factorials
- Use trigonometric, logarithmic, exponential, rounding, minimum, maximum, `gcd`, `lcm`, `nPr`, and `nCr` functions
- Choose angle units: **Degrees**, **Radians**, or **Gradians**
- Read responsive expression and result displays with clear validation errors
- Review completed calculations in persistent local history

---

### 🎬 Function Graphing

- Plot expressions such as `sin(x)` and `x^2 - 4` on an interactive canvas
- Drag to pan and use pinch gestures to zoom around the graph
- Show or hide the coordinate **grid** as needed
- Reset the graph viewport at any time
- Enter functions directly with an expression field and contextual guidance

---

### 📂 3D Formula Models

- Build formula surfaces by entering `z = f(x, y)` expressions
- Drag to rotate the model and pinch to zoom the camera
- Explore rendered mathematical surfaces in a dedicated **3D Model** workspace
- Reset the camera to return to the default viewing angle
- Keep the formula workspace separate from calculation history and graphing tools

---

### 🌐 Local Mathematical Python

- Built-in **Python Workbench** for local mathematical code
- Runs safe mathematical Python code directly on the device
- Imports, file access, and network access are disabled by design
- Provides a focused code editor, help text, and clear execution feedback

---

### 🎨 Personalization

| Option                        | Details                                                                 |
| ----------------------------- | ----------------------------------------------------------------------- |
| **Display Mode**              | Switch between compact Basic and expanded Scientific calculator layouts |
| **Theme Mode**                | Light, Dark, and System-following appearance options                    |
| **Color Source**              | Dynamic system colors, curated presets, or a custom seed color          |
| **Typography**                | Google Sans Flex supports clean, expressive displays and metadata       |
| **Interaction Settings**      | Select angle units and optionally enable haptic feedback                |

---

### 📱 Interface Highlights

- Dedicated workspaces for Calculator, Graph, 3D Model, Python, History, and Settings
- Rounded Material 3 controls with responsive layouts for different screen sizes
- Local calculation history with an empty-state view and clear-history action
- Adaptive typography powered by Google Sans Flex

## 📋 Requirements

## 🔒 Privacy

| Aspect                              | Details                                                                 |
| ----------------------------------- | ----------------------------------------------------------------------- |
| **No Tracking**                     | No advertising SDKs, analytics, account sign-in, or cloud backend       |
| **Local Storage**                   | Settings and calculation history are stored locally on your device      |
| **No Network Dependency**           | Core calculator, graphing, 3D modelling, and Python tools work offline |
| **Python Sandbox**                  | Imports, files, and network access are disabled for local Python code  |
| **Input Processing**                | Mathematical expressions are evaluated locally within the application   |
